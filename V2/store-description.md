## Full description (paste as-is)

Requires Microsoft .NET Desktop Runtime to run.

HL7Tester — your HL7 v2 toolbox for integration testing

HL7Tester is a fast, intuitive desktop tool for healthcare developers, integrators, and IT teams. Generate realistic HL7 v2 messages, inspect them down to the last component, and send them to any HL7 interface — no complex configuration, no ceremony.

GENERATE REALISTIC HL7 MESSAGES
• ADT (all 30 event types, A01–A40), ORM orders, and SIU scheduling
• Patient, encounter, and order details fully editable
• Unique Control IDs generated automatically — or refresh just the ID to replay a message the receiver rejected
• Drag & drop existing .hl7, .txt or .msg files straight into the app

SEND AND VALIDATE INSTANTLY
• Send messages over MLLP to any HL7 server on your network
• Read acknowledgments at a glance: AA / AE / AR status with the receiver's error text
• Choose your message encoding (UTF-8, Windows-1252, ASCII, or a custom code page)
• Save servers with nicknames and switch between environments in seconds

INSPECT ANY HL7 MESSAGE
• Expandable tree view: segments, fields, components and sub-components
• Built-in knowledge base: 50+ segments with field names, data types and required flags
• Click any value to copy it to the clipboard
• Fully offline — no external services required

STRESS-TEST YOUR INTERFACE
• Batch Send runs parallel patient workflows (admission, transfer, discharge…) against your server
• Randomized patient data, ready-made workflow templates, and configurable delays
• Reuse a single connection for high-throughput runs
• Ideal for load testing and verifying production behavior

DESIGNED FOR DAILY USE
• Clean, modern interface with light and dark themes
• Automatic update checks
• Local log files to troubleshoot every send

Hl7Tester is intended for development, testing, and educational purposes when working with HL7-based healthcare systems.
